## ② 仕分け
| 名詞 | 分類 | 英語の名前 | 理由（〇〇の何？／何から計算できる？） |
|---|---|---|---|
| 支出 | クラス | Expense | 日付・金額・項目を持つ（1件分） |
| 特別支出 | クラス | SpecialExpense | 日付・内容・金額を持つ（1件分。項目は持たない） |
| 固定費 | クラス | FixedCost | 名前・金額・毎月何日を持つ（1件分） |
| 予算 | クラス | Budget | 年月と金額を持つ |
| 家計簿 | クラス | Kakeibo | 支出をたくさん持ち、追加・合計する |
| 項目 | enum | Category | 選択肢：食費・日用品・交通・趣味 |
| 金額 | 値 | amount | 支出・特別支出・固定費・予算の金額 |
| 日付 | 値 | date | 支出・特別支出の日付 |
| 内容 | 値 | content | 特別支出の内容 |
| 何年・何月 | 値 | yearMonth | 予算の年月 |
| 今月の予算 | 値 | （Budget の amount） | 予算の金額と同じ |
| 貯金額 | 値 | savings | 家計簿の貯金額（今の残高。自分で書き換える） |
| 今月使った金額 | 計算結果 | totalSpent | 今月の支出の金額を全部足す |
| 月の合計 | 計算結果 | （totalSpent） | 今月使った金額と同じ |
| あと使える金額 | 計算結果 | remaining | 予算 − 今月使った金額 |
| まだ使っていない分 | 計算結果 | （remaining） | あと使える金額と同じ |
| 残り日数 | 計算結果 | daysLeft | その月の日数 − 経過した日数 |
| 1日あたりに使える金額 | 計算結果 | dailyAllowance | あと使える金額 / 残り日数 |
| % | 計算結果 | ratio | その項目で使った金額 / 予算 × 100 |
| 特別支出の合計 | 計算結果 | specialTotal | 今年の特別支出の金額を全部足す（予算とは別） |
| 最後に追加されたもの | 計算結果 | lastExpense | 家計簿が持つ支出の List の最後の1件 |

## 決まったこと（2026-11-15）
- 項目別グラフはドーナツ型にする（輪1本を、食費・日用品・交通・趣味・まだ使っていない分の5つで区切る）
- ドーナツの描き方は、項目別グラフとホームで使い回す
- 固定費は予算の中に入れる（月初めに「今月使った金額」へ自動で足す）
- 固定費と貯金額は、第10週の後に足す追加機能にする
